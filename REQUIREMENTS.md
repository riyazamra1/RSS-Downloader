# RSS Downloader Requirements

Functional reference for the RSS KIT account standard.

Requirements:
- Preserve the existing Downloader product scope and its own UI/branding.
- Its account implementation may be used as the reference for standardized Google/Gmail + Email registration, RSS Core connection, verification, cloud/multi-device sync, and Premium entitlement.
- Do not copy Downloader UI into other RSS apps.
- Verify authentication and sync behavior with real tests.
