# RSS Downloader Build

The repository now has a strict TypeScript project manifest and `tsconfig.json` covering the RSS Core and RAY TypeScript sources.

## Local verification

1. Install Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run typecheck`.

The browser UI remains plain HTML/CSS/JavaScript and does not require a frontend framework.

A CI workflow will be added once the repository's GitHub Actions integration is available for this project.
